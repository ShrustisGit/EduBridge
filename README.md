# EduBridge
EduBridge is a web-based platform that connects students with investors by providing a centralized space to showcase innovative projects and seek funding opportunities. The platform helps bridge the gap between student innovation and investment by enabling direct communication and collaboration.

Features:-
Student Registration and Login.
Investor Registration and Login.
Student and Investor Profile Management
Project Upload, Update, View, and Delete
PDF Document Upload and Download
Project Listing and Detailed Project View
Real-Time Communication and Chat System
Contact via Email, Call, and WhatsApp
Interactive and Responsive User Interface
Multi-Language Support
Chatbot Assistance
Secure Authentication and Session Management
